Available Tools

This section collects small utilities used to support content, publishing, and research workflows.

Hosted Streamlit Tools

Streamlit-hosted analysis tools are grouped here as this collection grows.

Comprehensive Reliability Analysis

Streamlit

Open the hosted Streamlit tool for comprehensive reliability analysis across inter-rater and intra-rater workflows.

Bland–Altman & Reliability Suite

Live

Run agreement and ICC analyses with Bland–Altman plots, limits of agreement, confidence intervals, datasets, and report exports.

Confusion Matrix Calculator

Streamlit

Open the hosted Streamlit calculator for confusion matrix metrics and related diagnostic test outputs.

Tendon & Achilles Teaching Tools

Interactive models for teaching tendon and Achilles mechanics, from fibrillar sliding and cross-linking up to whole-tendon load sharing.

Tendon Cross-link Explorer

Live

Interactive model comparing enzymatic and AGE cross-linking effects on tendon stress–strain response, fascicular sliding, and load distribution.

Tendon Hierarchical Sliding

Live

Interactive model showing how a tendon lengthens mainly through inter-fibrillar sliding rather than stretching, tracked with fiducial lines across the structural hierarchy.

Achilles Deep Fibre Shortening

Live

Material-body model of the Achilles tendon showing deep insertional fibres shortening as superficial fibres lengthen through dorsiflexion.

Triceps Surae & Achilles Load Sharing

Live

Interactive model of medial gastrocnemius, lateral gastrocnemius, and soleus bundle recruitment and how it redistributes regional load across the Achilles subtendons.

The Shifted Arc

Interactive

Teaching tool showing how humeral torsion shifts the rotational arc, helping explain why GIRD can represent a bony shift rather than only soft-tissue restriction.

The Misaligned Dynamometer

Interactive

Interactive teaching tool showing how dynamometer tilt and pad drift affect measured force, lever arm, and torque during strength testing.
