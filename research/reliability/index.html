Overview

This page reserves the Whiteley Work route for the Reliability application. The underlying project is a Flask web app for CSV and XLSX upload, ICC analysis, typical error, Bland-Altman plots, and report export.

Current status

The application repository is live and deployment-ready, but the hosted app has not yet been published behind this site route. This page prevents a 404 and provides a stable destination while deployment is completed.
